# ابسو | د شعرونو نړۍ

A starter Pashto poetry application built with Flutter and Material 3.

## Included
- Right-to-left Pashto interface
- Material 3 styling
- Search and category filters
- Favorite toggle UI
- Light and dark themes

## Run
Install the Flutter SDK, then run:

```bash
flutter create --platforms=android --project-name abso .
flutter pub get
flutter run
```

The current release is a starter UI with sample text. Review and replace sample poetry with verified, correctly attributed poems before publishing.
